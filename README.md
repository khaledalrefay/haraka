# حركة — beta8 (تحسين الواجهة والتنقل)

تطبق هذه الحزمة تحسينات الرئيسية والتمرين والاستراحة والإعدادات والسجل، مع أسماء وصفية للجلسات والمستويات. نقطة البدء للتطوير هي `site/js/app.mjs`، وللنشر **محتويات `dist/` فقط**. لا ترفع المشروع كله إلى مجلد الأصول في الاستضافة.

## الاستخدام
- `Haraka-Preview.html`: معاينة مستقلة دون خادم؛ لا تختبر التثبيت والإشعارات من هذا الملف.
- `dist/`: ملفات النشر الجاهزة. حافظ على نطاق الموقع ومساره الحاليين حتى تبقى بيانات المتصفح والتثبيت متاحة.
- `site/`: كود الواجهة واختباراتها. لا تعدّل `app.bundle.js` يدويًا.
- `reminder-server/`: Worker التذكيرات وD1؛ لم يتغير مخططه أو إعدادات نشره في هذا التنظيف.
- `artwork/`: 16 صورة محفوظة للدمج اللاحق، ليست ضمن أصول النشر الآن.
- `content-source/`: المصدر المعتمد للحركات والخطط وتقديرات المدد.
- `ARCHITECTURE-AR.md`: المعمارية والبيانات وحدود المراجعة ونتائج الاختبارات.

## البناء والاختبارات
المتطلبات: Node.js وnpm وPython 3. ثبت الأدوات من ملف القفل داخل `site`:

```sh
cd site
npm ci
npm run build
npm test
npm run test:pwa
npx playwright install chromium
npm run test:browser
```

إن لم يكن Python متاحًا باسم `python3` على Windows، نفّذ `python ../tools/build-preview.py` بدل `npm run build`.

الفحص المعماري: `python3 ../tools/check-architecture.py` من داخل `site`.
اختبارات الخادم: `node ../reminder-server/tests/server.mjs` (يحتاج Python 3 أيضًا).
لا تنشر اختباراتك أو ملفات المصادر؛ البناء يعيد توليد `dist/` من قائمة أصول التطبيق.
اختبار الترقية الاختياري: `node tests/vnext/upgrade.browser.cjs` مع متغير البيئة `BETA6_SITE` الذي يشير إلى مجلد `site` من beta6. ولتحديد متصفح مثبت خصص `CHROMIUM_PATH`.

## ما الذي تعدله؟
- المنطق: `site/js/domain/`؛ التخزين: `site/js/infrastructure/workout-repository.mjs`.
- الشاشة: `site/js/presentation/` والتنسيقات في `site/css/`؛ التنسيق العام للشاشات الأخرى والأحداث في `site/js/app.mjs`.
- المحتوى: عدّل مصادر JSON ثم نفّذ `python3 tools/build-content.py` من الجذر، وأعد الاختبارات والبناء.
- الإصدار: حدّث `site/package.json` وملف القفل؛ البناء يولّد رقم الواجهة وبصمة كاش جديدة.
- رابط التذكيرات: `site/config.js`، ثم أعد البناء. ملف إعداد التذكيرات الداخلي يقرأ هذا الإعداد.

لا تمسح IndexedDB أو بيانات الموقع عند التحديث. النسخة الجديدة تنتظر إغلاق نوافذ التطبيق القديمة قبل تفعيل Service Worker الجديد. لم تُنشر هذه الحزمة بعد.
